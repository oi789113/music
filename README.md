# 听潮 SONAR

现代音乐探索界面：动态极光背景、可拖动的封面叠层、模糊转场、横向热歌浏览、悬浮播放器和沉浸播放视图。保留双平台榜单、官方试听、收藏与心情推荐。

## 构建

无第三方依赖。`npm run build` 将页面、样式、脚本与真实榜单快照打包为 `dist/server/index.js`，默认导出 Cloudflare Worker fetch handler。`npm test` 执行推荐、Worker 路由与真实页面脚本的 DOM 交互检查。`motion.js` 提供按需运行的指针视差，背景使用 CSS transform 动画，支持减少动态效果偏好与后台暂停。

## 数据与更新

`/api/charts` 从网易云热歌榜与 iTunes 美国榜读取公开数据，按 UTC 日期使用 Workers Cache API 缓存。当日首次访问获取，无需每天重新部署。源异常时使用注明原更新时间的构建快照，15 分钟后重试。没有声称覆盖全网所有平台或生成全球统一排名。平台独立排名交替呈现。

推荐是本地类型、标题关键词、榜单排名与收藏偏好的规则排序；每日种子变化，点击重新生成可探索不同选择。收藏和音乐口味保存在 localStorage。音频仅使用上游官方试听链接，不下载或提供完整版权音频。

## 播放栏折射与滚动

`glass-optics.js` 根据圆角矩形曲面与折射角生成位移图。`glass-renderer.js` 只为播放栏附近的可见内容创建小块、不可交互的视图；先裁切，再进行单次 SVG 位移，最后通过渐隐遮罩限定到 12px 的弧形边缘。中间使用浏览器实时背景，配合 2px 的轻微柔化与暗色透光层保持文字可读。折射来自位移图，而不是模糊滤镜。

不复制整页，不读取 WebGL 帧缓冲，不通过 MutationObserver 监视整页样式。位移图仅在底栏尺寸变化时重建，Safari 的 visualViewport 变化只更新位置。快速惯性滚动时暂停小块折射重绘，原生透光层继续实时合成，停止后平滑恢复边缘细节。歌曲和段落在滚动时始终可见，不再等待整块模糊入场。触屏关闭悬停倾斜，底栏适配安全区域。首次加载短暂采样帧间隔，持续掉帧时暂停背景等装饰循环，保留滚动、折射与交互反馈。

验证：`npm run build && npm test` 检查推荐、数据回退、页面交互和光学映射。浏览器验证覆盖平板横屏、手机窄屏、连续上下滚动、窗口高度变化、横向浏览、收藏、沉浸视图和减少动态效果。

## GitHub Pages

静态网站使用 `docs/` 目录。运行 `npm run build:pages` 生成网页与 `docs/api/charts.json`；联网时将从网易云热歌榜和 iTunes 美国榜获取最新数据，单个平台失败时沿用已有、保留时间的快照。网站在访客打开时还会尝试从 iTunes 获取实时数据，音乐推荐、试听、收藏均在浏览器工作。

仓库的 GitHub Actions 每天 01:10 UTC 刷新两份榜单并更新 `docs/`，更新后会主动请求 Pages 重新构建；也可以在 Actions 中手动运行 “Update daily music charts”。GitHub Pages 需使用 `main` 分支的 `/docs` 目录作为来源。
